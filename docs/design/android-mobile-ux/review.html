自己的信息架构与视觉语言

入口是「连接」工作台：已有主机、活动会话、待恢复会话；新用户直接看到「添加主机 / 快速连接」。 主机代表连接配置；凭据、已验证主机密钥、tmux 会话身份是三个独立对象。 保存主机不会自动保存密码。相同主机的不同账号有不同密码条目。 第一批支持简单本地列表；分组、跨端同步、SFTP、广播输入与多终端分屏暂不加入。

登录成功进入一个专注终端。单一 48dp 会话状态条显示 会话名 · user@host、连接/只读/鼠标等 必要状态，并提供独立Home、键盘与更多入口；完整身份、端口、指纹在详情中可读。 窄屏标题显示会话位置/总数，点击选择器、左右拖动切相邻会话；宽屏同一顶栏提供可横滚Tab。 保留最多四个独立连接和完整 tmux 身份去重。 系统返回先关闭临时面板/选择，再收起 IME，再返回工作台，不发送 Esc，也不默认停止连接。 连接仍在后台时，工作台和通知均可停止。预测返回接线使用 Android 支持的回调。

视觉采用沉静的深灰蓝表面、浅色文字、少量薄荷绿操作提示。身份用单行高权重文字； 终端以内容为主，不重复大品牌标题。普通错误用琥珀色，主机校验失败用红色并带明确文字。 接管是危险动作，独立确认；成功、只读、未连接均有文字，不靠颜色。无竞品标志或装饰图片。

关键流程

连接 → 首次指纹核对 → 认证 → 直接终端或 tmux 列表。拒绝信任/取消不得保存密码。 勾选「更新保存密码」后，只有该目标通过主机校验并认证成功才原子替换。 删除后当前已认证 SSH 可以继续，但同目标内存重连密码清除、待认证/自动重连取消。 恢复核对 host/key/account/UID/socket/server/session 完整身份；不存在/替换即停止。 有客户端时自动恢复暂停；共享、只读、接管为可选项，接管再确认，不自动选择。 激活目标输入租约 → 若用户原来打开键盘则恢复该目标键盘；不复制凭据或 attachment。 用户明确启动服务 → Home/锁屏/展开保留连接能力 → 通知返回或停止全部连接。 等待网络/认证/主机校验/占用/身份失败有各自状态 → 返回 app 处理；普通 SSH 需手动重连新 shell。

  • 首次连接：新增/快速连接 → host/port/account/auth → 可选保存主机、默认关闭保存密码 →
  • 密码使用：已保存条目显示「使用此设备保存的密码」，不回填 DOM；「本次改用其他密码」不覆盖旧条目。
  • tmux：按所选 socket 列表 → 共享/只读明确选择 → 新建命名仍原子拒绝重名 → 登录终端。
  • 会话切换：打开选择器 → 点击目标 → 清除旧 composition/修饰键/鼠标手势与未确认粘贴 →
  • 后台：用户在前台开启「后台保持连接」 → 说明通知用途 → Android13+ 由用户决定通知权限 →
  • 网络失联：即时禁止输入、保留本地画面且标「已断线」 → 有完整 tmux 身份/可用认证时有限重连 →

字号、网格、屏幕和面积预算

几何用 dp；UI 文字初值 body16sp、label14sp、title20sp，随系统设置缩放。 终端单独初值16sp，用户范围12–26sp，1sp步进、恢复默认、显示实时列×行；不按窗口宽度自动缩小。 12sp只供用户主动选择，默认仍16sp。双指缩放更改字体与 PTY 网格，不对整屏做 CSS transform。 Android14+ 非线性 sp 转换用 TypedValue.applyDimension，不简单乘 fontScale；WebView CSS px 与 dp 按实际 viewport/density 校准，文字 px 从原生转换后再除 density。控制尺寸不随 sp 缩小。

Find N6 官方内屏2480×2248、外屏2616×1140是面板像素；不能由 PPI 推导 ColorOS 实际逻辑密度或 app窗口。 下面是假设的设计窗口，已排除系统栏/切口，IME高度另列；不声称是 Find N6 实测。 正式验收记录 density、fontScale、原生window/WebView/visualViewport与可见IME/insets，仅数值、不含终端文本。

计算：cols=floor((W−水平padding−已固定面板)/实测cellW)， rows=floor((H−IME−状态条−常驻快捷键−垂直padding)/实测cellH)。 这里只用16sp、单元9.6×20.8dp、padding每边8dp作估算；xterm真实指标和 stty size 才是验收值。

原生实现先用ViewConfiguration.scaledTouchSlop判定移出点击容差，再转换到CSS坐标。 讨论中的初值：横移超过容差，且abs(dx) >= 1.5*abs(dy)才锁定标题横拖； 释放时abs(dx) >= max(48dp,有效标题宽度20%)才切换，不只靠高速短甩。 不足门槛/拖回起点则回弹；一旦超过点击容差，本次不能顺便打开列表。 第二指、pointercancel、失去所有权、Home/返回、模态出现、折叠或输入代际变化都取消。 系统边缘返回区域优先；不修改系统手势排除设置。长按标题不重排、不关闭。 离线点击稿仅以8 CSS px容差模拟，不是Android实际dp/touch slop验收。 官方依据仅是容差和取消语义： ViewConfiguration)、 事件拦截与ACTION_CANCEL； 48dp/20%/1.5是本方案候选值，待真机调校，不称为Android标准。

宽屏Tab拖动超过容差只滚动，不选中；默认没有挨着标题的小关闭叉。 关闭/重排放进「管理会话」：独立≥48dp移动前/后和「断开并关闭」确认。 状态变化、收到输出不会重排或抢焦点；断线项留原位置且标「已断线」。 切到断线项只看旧画面及恢复入口，不自动重连/认证。关闭连接取消恢复意图，不杀远端tmux。

每个会话保留独立buffer、回看锚点/跟随模式、字号、键栏位置与完整身份。 切换不重新连接、重发输入或fit隐藏pane；先取消旧composition、Ctrl/Alt、鼠标手势与待确认粘贴， 再换活动输入租约。已发送输入仍属于原会话；未提交中文预编辑本地取消，不提交到任一目标。 如果以后提供已提交未发送草稿，只在所属连接前台内存保留，切回后明确确认才能发送； 本轮不新增草稿/待发命令队列，更不存磁盘。 可写→可写尽量保持IME打开，租约有效后才聚焦；只读/断线取消聚焦并收起IME， 记录用户键盘意图，回到可写会话后走安全焦点路径恢复。折叠保持连接与意图，只重算布局。

Home位于顶栏左侧，独立≥48dp目标与「回到连接与会话」标签，不参加标题滑动。 点击取消在途手势/预编辑/修饰键、收起IME再回主页，不关闭SSH、不重置视口， 也不自动开启后台服务。主页显示活跃/待恢复/已停止，可新建连接或返回原终端。 Home直接导航；系统Back先关闭模态/选择/IME，再回主页；二者都不等于断开/通知停止。 信任、接管、粘贴确认中必须先取消操作再Home，不能绕过安全确认。 未保存表单需要留存/放弃提示；原稿面板返回入口保留，独立Home是本轮新增提案。

快捷键分组：Esc / Tab / Ctrl / Alt → ← ↑ ↓ → → Home / End / PgUp / PgDn / Del / Ins；F键从「全部键」进入，常用优先。 这里的Home终端键是远端光标移动，与应用Home入口位置/辅助标签不同。 横拖只找键，点击才触发，pointerdown不发送。超过容差后取消点击，即使拖回原点也不发键； 离开原键、cancel、第二指、切会话/后台/断线也取消。到首尾停住，不循环或切会话。 每键≥48dp，示意常用键56dp，不压窄塞满；边缘渐变/箭头及部分下一键提示可滚动， 部分露出的键先滚到完整可见再点。固定「全部键」≥48dp入口提供可点按分组面板。

Ctrl/Alt默认单次：点选，下个明确用户终端按键消费后解除；再次点解除。 锁定从「全部键→修饰键→锁定Ctrl/Alt」开启，不用隐藏双击/长按区分滚动。 单次/锁定用文字和颜色共同反馈，并在键栏固定区域显示可点击解除的状态，不能滚出后暗中生效。 锁定只属当前会话，切换、Home、断线、只读、后台时清除。协议应答不消费单次状态； composition时先完成/取消本地预编辑，不把IME内容转成Ctrl/Alt序列。 只读/断线时可回看/滚动键栏，发送/锁定禁用，不排队到重连。 IME收起键栏消失；横屏短窗口默认折叠，从更多访问；展开只增加同一行可见键数，不加第二行。

TalkBack提供会话列表、上一/下一会话动作、全部键分组和修饰锁定开关，不抢读屏左右滑。 Tab有「名称、主机、只读/断线、第几项、选中」标签；UI里的外接Tab导航， 终端焦点里的Tab仍发补全。关闭面板恢复入口焦点；大字允许重排/滚动。 新增设计检查：标题短拖/回拖/纵拖取消、首尾不循环、每次一项、Home独立； 键栏拖动/cancel零模拟按键，完整按键点击才一次；锁定可见且切会话清除； Tab拖动不选中、点击选中；只读/失联拒绝输入；Home往返保留视口。 原生IME、系统Back/TalkBack、Android触控与PTY零额外输入仍需后续实际验收。

SSH密钥现状与可选“设置密钥登录”提案

基线ded417ba已经支持密码、私钥文件与交互认证： 表单与口令、 原生导入/一次性keyId、 私钥认证。 普通/加密OpenSSH文件从系统文档选择器临时读取，不取持久URI授权；私钥限64KiB、 内存最多4份、消费后清零字节，不能宣称JVM/Rust所有复制都安全擦除。 私钥口令临时参与解密；加密KDF有成本限制，不保证接受任何加密文件。 现有fixture覆盖生成的普通/加密Ed25519；RSA代码限制≤8192bit且必须有SHA-2、不退回SHA-1。 其他算法的库代码能力不当成Android已测试支持列表。没有mobile agent或Keystore持久密钥库； 私钥/交互认证恢复需显式重新导入/提供凭据。这些不同于本设计待实施的密码保存。 本次查找未见ssh-copy-id/写authorized_keys的产品路径，不能把密码登录说成自动安装密钥。

可以设计单独的「设置密钥登录」，但用户此次询问不是服务器写入授权： 密码登录成功并核对主机 → 用户主动选择此操作 → 导入已有私钥并只提取公钥， 或后续另行设计本地生成 → 展示目标host:port、实际账号、已验证主机指纹、公钥算法/指纹 → 明确确认「把此公钥加入该账号」 → 隔离控制通道去重添加 → 新独立连接仅公钥认证验证 → 显示已验证/仅添加待验证/失败，原密码连接保持可用。不发送私钥或口令到服务器。 不同主机/账号逐个确认，不广播。Keystore AES包裹文件与非导出硬件签名密钥是两种架构， 不能将加密存储私钥文件冒称硬件签名；agent转发、密钥持久保存和生成另列后续范围。

受限账号、只读主目录、定制AuthorizedKeysFile/集中目录或策略不允许写入时停止，交管理员处理； 不sudo、不改sshd设置、不放宽已有目录/文件权限。必要的新用户目录/文件只在普通安全路径核实后 以700/600创建；无法核实所有者、ACL或路径策略时停止，不自动“修复”已有权限。 安装器若未来实现，必须避免符号链接和并发覆盖， 按算法+公钥blob去重，保留已有行及from/command等限制，不能因同key带限制就加一条无限制重复key。 仅在有权限且状态可核实的常规用户目录追加必要内容，不能替换整个文件。 验证失败不是安装未发生；超时可能结果不确定。回滚只能在重新核对文件版本与精确新增条目后， 由用户确认删除本次新增行，绝不删已有key；无法证明所有权/并发状态时保持并报告，不盲目回滚。 提供“复制公钥供管理员安装”备选。新连接必须再次校验原主机身份，仅认证验证不等于允许PTY： 受forced-command或MFA限制时分别显示公钥已接受/仍需认证/终端受限，不能用通用成功掩盖限制。 尚需决定支持的算法实测范围、生成/持久保存架构与服务器策略。 这次只有设计流程和虚构指纹，没有生成真实密钥、输入真实凭据或操作任何SSH服务器。

用户已新增“允许时自动生成SSH key并完成公钥安装”的产品设计需求。推荐入口为 「密码登录成功 → 设置密钥登录」，默认不生成；确认生成与确认服务器安装分开。 界面可串联执行生成/安全保存/添加/验证，但每个目标均需明确确认，不因用户允许生成就允许所有服务器写入。 生成失败、Keystore不可用或存储写失败不降级明文，也不上传临时私钥； 安装失败仍保留已有本地密钥和密码登录，显示“仅在此设备生成，未确认服务器安装”。

默认每个已验证host:port/account使用独立设备密钥，名称如“此设备 · 实验环境 · demo”； Keystore alias使用随机内部ID，不带主机/账号。多主机共用同一key作为显式选项， 逐个确认目标、分别记录添加与公钥认证验证结果，删除/轮换前展示关联目标，禁止静默广播安装。 设备管理区列出公钥指纹、创建时间、关联目标与验证状态；不会把公钥备注当成身份校验。

首批候选是经过测试的SSH库本地软件生成Ed25519，再以Keystore AES-GCM密钥包裹OpenSSH私钥， 密文进入noBackupFilesDir并排除云备份/设备迁移；只有原生认证路径临时解密，网页仅持keyId与公钥信息。 这不等于Ed25519私钥始终不可导出或硬件签名，不能声称所有设备支持此算法的Keystore/StrongBox签名。 若未来选择原生非导出RSA/EC签名路径，需另外实现SSH公钥序列化与签名适配、验证具体设备及算法； OpenSSH私钥文件不能直接冒充Keystore签名句柄。 服务器/FIPS策略不接受候选算法时明确报错，用户选择经测试的替代算法或管理员指定密钥，不自动降级。 依据：Android KeyProperties、 Keystore、 OpenSSH ssh-keygen。

无自动云同步、默认不导出私钥。只导出公钥是低风险安装入口； 私钥手动导出另经明确确认，候选格式为用户口令保护的OpenSSH文件，提示复制文件会扩大凭据暴露面， 不能把仅此设备能解密的Keystore密文当作可迁移备份。重装/密钥丢失会使加密私钥不可用， 需保留密码或管理员备用登录方式；本任务不接收任何实际备份、口令或密钥。 删除本地key清除同目标内存认证与重连意图，不自动删除远端authorized_keys； 远端仍有公钥需另行逐目标确认撤销。当前已认证SSH是否断开由用户另选。 轮换为先生成/安装/新连接验证，再明确移除旧授权，失败保持旧访问。取消首次安装不会清空已有密钥。 待最终决策：默认独立key策略、算法兼容实测范围、是否首批提供私钥导出、交互式解锁与后台重连的取舍。

后台、安全和状态文案

第一批后台目标是「本次用户启动的SSH会话尽量保持」。建议独立原生service拥有transport/generation/worker， Activity/plugin只订阅、发送带owner+generation的用户动作。后台不依赖WebView timer。 已验证连接可在后台继续；首次信任、密码提示、键盘交互、接管都暂停到前台。 启动时核实app可见并及时进入foreground，失败清理资源且UI显示「后台保持未开启，连接仅在前台使用」。

前台服务类型选择 specialUse 并写明用户发起的交互式SSH持续会话；这是对官方类型定义的工程判断， 尚不是Play批准。SSH不冒充聊天、媒体或三分钟任务；不以新增CHANGE_NETWORK_STATE权限凑类型。 Android15+ dataSync有六小时后台上限，不用于伪装无限终端。 通知默认隐去锁屏主机/账户细节，显示「Tabby · 2个连接」「返回」「停止全部连接」。 本产品选择可见通知作为后台开关的前提；Android13拒绝通知并非系统禁止FGS，文案必须区分这个产品选择。 权限仅在用户开启时请求，拒绝后提供前台模式；不改省电、安全、ADB授权或持久文件权限。

服务 START_NOT_STICKY，无boot receiver/自动重启/周期任务。通知停止立即增加epoch、取消重连、 关闭所有transport、清除内存凭据/输出并stopSelf；tmux服务器上的会话不被kill。 系统Active apps停止整个进程可能无回调；重新打开只显示可恢复入口，不自动连接。 划掉任务与配置重建分别测试；后台开关开时任务划除可保留服务，关闭时清理。 锁屏/Doze/OEM可能暂停网络或终止进程，没有永久wake lock或不断线承诺。

原生输出只保留有界内存序列队列，延续1MiB背压；前台按parse→ACK确认。 后台高输出填满队列时明确关闭并标「输出积压，等待返回后恢复」，不丢原始VT字节、不写日志文件； tmux可在返回后新PTY显示远端当前画面，但缺失的本地历史不能假装完整。 自动恢复有限退避（1/2/4/8/16/30秒，最多6次约1分钟，网络离线时等待并设总期限），用户可随时停止。 初始建议整个恢复窗口不超过120秒，离线等待也计入；后续实现需单调时钟和可控时钟测试证明期限。 网络回调只是信号，不当作SSH成功；恢复再核对完整身份，不重放命令、create或takeover。 后台若需安全确认/认证立即暂停，通知「需要返回应用处理」。普通SSH断线仅手动重连，提示新shell。

密码默认不保存，仅支持此设备。原生Keystore AES-256-GCM、随机nonce、版本化封装， AAD绑定规范host+port+case-sensitive account+已验证主机公钥摘要；密文存 noBackupFilesDir， 结合已有allowBackup=false和明确cloud/device-transfer排除规则。 Keystore不可用、密钥丢失、篡改、写失败均禁止明文降级，原子更新失败保留旧密文。 alias不含用户名；秘密不进入localStorage、saved tmux身份、Intent extras、日志、崩溃报告、Git或artifact。 保存条目在native内解密并响应认证，不把已有密码回传DOM；真正保存发生在对应host校验和认证成功之后。 当前输入不可避免暂经Web表单/JVM/Rust内存，清零仅best effort，不宣称无复制或flash安全擦除。 第一批不要求生物认证密钥以免自动恢复不可用；不声称所有设备为StrongBox。
