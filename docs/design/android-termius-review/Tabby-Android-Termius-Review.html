此图 840×450 为设计单位，不是 OPPO Find N6 的逻辑尺寸。实际铰链/遮挡由原生窗口信息决定。大字或短窗口装不下 Tab 时回退标题选择器，不缩字挤入；手势仍限定标题区。

优先级与实施边界

P0 · 下一轮推荐，先做低风险层级改造
  • Home 区分活跃连接/待恢复 tmux，独立“管理会话”；关闭改为明确“断开并关闭”，不杀远端 tmux。
  • 标题加入滑动方向/下拉暗示；只读、断线、可写清楚标记，不用单一绿色点承诺安全。
  • 更多单分为输入、会话、连接/凭据、外观；危险断开独立。凭据与主机信任仍走原生确认。
  • IME 关闭/外接键盘时默认收辅助键栏，可显式调出；保留真实输入行。断线保留只读旧画面与恢复解释。
  • 使用本项目统一视觉 tokens，淡化无关边框，不改共享 ANSI 色板或 Linux 配色。
P1 · 两项各自单独验收
  • 本地命名主机库：别名/搜索/收藏。需新增原生 noBackup 元数据模型；凭据只存原生引用，按 host/port/account/pin 绑定。不能只把当前标签列表换个标题。
  • 局部可见输入编辑器：沿用原生输入租约、真实焦点、composition、选择及触控保护；所有门槛通过前继续保留 48dp 输入行。
  • 两项都需独立候选与精确 SHA 全矩阵；本轮不直接改产品。
P2 · 后置 / 不推荐当前引入

可选键组排序与外观偏好；复杂嵌套标签、手势箭头模式后置。Termius Android 长按箭头 [S2] 与现有长按选择冲突，首批不默认采纳；iOS 文档的双击 Tab [S4] 也不作为默认远端输入手势。账号云同步、自动日志/命令历史、AI 生成执行、自动文件上传、凭据继承和批量执行不纳入本项目范围。

Home → 活跃会话 / 待恢复 / 本地主机（P1） → 指定终端。
终端 → 顶栏更多 → 分组操作。终端内不增加常驻底部管理导航。应用内 Home（⌂）/系统 Back/断开/通知停止是不同动作。Android 系统 Home 进入后台仍遵用户的后台保持开关；不会自动开启服务，也不承诺系统杀进程后在线。

字体与颜色

后续验收与评审选择

建议评审重点

  1. 先评 P0 Home / 状态 / 分组更多 / 键栏显隐。
  2. 确认本地主机库是否需要别名、搜索、收藏；不引入云账号。
  3. P1 输入方案作为单独技术候选；失败保留现版输入行，不扩大安全例外。

实现后必须保持

Home/切 Tab 不断线且无旧输入泄漏；横拖键栏不发键；标题滑动有点击替代。主机变更拒绝、tmux 重名/不存在报错、显式接管、多行粘贴确认、密码/密钥删除与后台通知停止继续验证。

重新跑精确 SHA、API31–37 矩阵、ARM64 包绑定与真实截图。OPPO 折叠、用户中文 IME 与网络切换须另行真机验收。
